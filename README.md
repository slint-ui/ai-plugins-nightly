# Slint AI plugins (nightly)

Nightly build of the official Slint plugin and skills for AI coding agents.
It follows Slint's `master` branch: the skill covers unreleased features, and
the Slint preview runs the latest development build of Slint.
For the plugin of the latest Slint release, use
[slint-ui/ai-plugins](https://github.com/slint-ui/ai-plugins).

> [!IMPORTANT]
> **This repository is generated.** Its content is published daily from the
> [`ai-plugins/`](https://github.com/slint-ui/slint/tree/master/ai-plugins)
> directory of the [slint-ui/slint](https://github.com/slint-ui/slint) monorepo.
> **Do not edit files here**, since every sync overwrites them.
> Open pull requests against the monorepo instead.

## Install

See the [nightly release](https://github.com/slint-ui/slint/releases/tag/nightly)
for how to install the nightly plugin.
